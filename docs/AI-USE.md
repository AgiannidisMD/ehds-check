# How AI is used in ehds-check

- Code, tests, docs and translations in this repository are written with the help of
  generative AI coding agents (Anthropic Claude via Hermes / Claude Code).
- The owner (STOLOSDIGITAL) decides scope, reviews changes and approves releases.
- Agents work under the rules in `AGENTS.md`: synthetic data only, local-first,
  no clinical interpretation, pinned guide versions.
- SK and CS explanations are machine-written and are marked for review by a
  native-speaking FHIR professional (`docs/I18N-REVIEW.md`) before they are
  advertised as reviewed.
